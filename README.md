# RJ+ Pair Trading Terminal

RJ+ Pair Trading Terminal is a Dash app and pair scanner for IBOVESPA tickers. It analyses ratio pairs (RSI, MACD, Bollinger / z‑score) from CSV price files and shows scanner results and interactive ratio charts.

## Quick start

1. Create and activate a virtualenv:
```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
